Status: early prototype

Open Journalist was built as a prototype in November 2026. Features, labels and behavior will change. Do not use it with real research material yet. The repository on GitHub holds the full product concept, the architecture and its decision records, and the developer documentation.

Quick start

With Git, Python 3.11+ and Node.js 22 installed:

git clone https://github.com/open-journalist/open-journalist.git
cd open-journalist
./start.sh --demo     # macOS, Linux
start.bat --demo      # Windows

Open Journalist opens in your browser with the demo project “E-Auto-Check (Demo)”. Add a model endpoint under Settings → Models to use theses, claims and drafts. Details in the installation guide.

Contributing

Corrections from newsroom practice are the most valuable contribution at this stage: what in the workflow, the gates or the scenarios does not match how your newsroom works? Open an issue with the template “Correction from practice”. For code, read CONTRIBUTING.md; coding agents start with AGENTS.md.
